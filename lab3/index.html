Условия выполнения лабораторной работы

Хранится информация о названии тура, агентстве, описании тура, сроках проведения и условиях оплаты.

Необходимо реализовать следующий функционал:

  • Регистрация новых пользователей
  • Просмотр и резервирование туров
  • Пользователь может редактировать и удалять свои бронирования.
  • Оставление отзывов о турах
  • При добавлении комментария фиксируются:
    • Даты тура
    • Текст комментария
    • Рейтинг (от 1 до 10)
    • Информация о комментаторе
  • Подтверждение бронирования администратором через Django-admin
  • Формирование таблицы проданных туров по странам в клиентской части

Основные возможности

Регистрация и аутентификация пользователей

  • Возможность регистрации и входа в систему.
  • Только зарегистрированные пользователи могут бронировать туры и оставлять отзывы.

Список туров

  • Отображение всех доступных туров в виде карточек.
  • Возможность бронирования тура (кнопка становится неактивной, если тур уже забронирован).

Детали тура

  • Просмотр подробной информации о туре.
  • После бронирования кнопка "Зарезервировать" становится неактивной.
  • Возможность оставить отзыв.

Отзывы

  • Отображение отзывов в виде карточек (бенто-стиль).
  • Добавлять отзывы могут только авторизованные пользователи.

Продажи по странам

  • Статистика проданных туров по странам.
  • Данные отображаются в виде адаптивных карточек.

Мои бронирования

  • Просмотр списка своих бронирований.
  • Возможность отмены бронирования.

Установка и запуск

Системные требования:

  • Python 3.6+
  • Django 3.2
  • PostgreSQL
  • pip

Шаги установки

  1. Создайте виртуального окружения и его активация:

sh python -m venv venv source venv/bin/activate

  1. Установите зависимости:

sh pip install -r requirements.txt

  1. Запустите сервер разработки:

sh python manage.py runserver

  1. Откройте приложение в браузере:

http://127.0.0.1:8000/
