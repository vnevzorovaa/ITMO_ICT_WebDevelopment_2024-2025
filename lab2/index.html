Условия выполнения лабораторной работы

Хранится информация о названии тура, турагентстве, описании тура, периоде проведения тура, условиях оплаты.

Необходимо реализовать следующий функционал:

  • Регистрация пользователей
  • Просмотр и резервирование туров (с возможностью редактирования и удаления своих резервирований)
  • Написание отзывов к турам (с сохранением даты тура, текста комментария, рейтинга (1-10) и информации о комментаторе)
  • Подтверждение бронирования администратором через Django-admin
  • Таблица с проданными турами по странам

Функционал

Основные возможности:

Регистрация и аутентификация пользователей

  • Возможность регистрации и входа в систему.
  • Только аутентифицированные пользователи могут бронировать туры и оставлять отзывы.

Список туров

  • Все доступные туры отображаются в виде карточек.
  • Кнопка "Забронировать" становится неактивной, если тур уже забронирован.

Детали тура

  • Просмотр подробной информации.
  • Кнопка "Зарезервировать" становится неактивной после успешного бронирования.
  • Оставление отзыва.

Отзывы

  • Отображение отзывов в формате карточек.
  • Кнопка "Добавить отзыв" доступна только аутентифицированным пользователям.

Продажи по странам

  • Статистика по количеству проданных туров в разных странах.
  • Адаптивное отображение карточек.

Мои бронирования

  • Просмотр списка бронирований пользователя.
  • Возможность отмены бронирования.

Установка и запуск

Системные требования:

  • Python 3.6+
  • Django 3.2
  • PostgreSQL
  • Установленный pip

Шаги установки

  1. Создание виртуального окружения и его активация:

    sh python -m venv venv source venv/bin/activate

  2. Установка зависимостей:

    sh pip install -r requirements.txt

  3. Запустите сервер разработки:

    sh python manage.py runserver

  4. Откройте приложение в браузере:

    http://127.0.0.1:8000/
