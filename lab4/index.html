Основные файлы и их назначение

axiosInstance.js

Настроенный экземпляр Axios с базовым URL и токеном авторизации.

api/appointments.js

Функции для управления приемами:
- getAppointments – получение списка приемов.
- addAppointment – добавление нового приема.
- updateAppointment – обновление данных приема.
- deleteAppointment – удаление приема.

api/doctors.js

Функции для работы с врачами:
- getDoctors – список врачей.
- addDoctor – добавление врача.
- deleteDoctor – удаление врача.

api/medicalCards.js

Функции для управления медицинскими картами:
- createMedicalCard – создание карты.
- getMedicalCards – получение списка карт.
- deleteMedicalCard – удаление карты.

api/patients.js

Функции для работы с пациентами:
- getPatients – список пациентов.
- createPatient – добавление пациента.
- updatePatient – редактирование данных пациента.
- deletePatient – удаление пациента.

api/services.js

Функции для управления медицинскими услугами:
- getServices – список услуг.
- createService – добавление услуги.
- updateService – редактирование услуги.
- deleteService – удаление услуги.

Дополнительные функции

  • getCabinets – получение списка кабинетов.
