Задание 1.

Зарегервированный тур пользователя

>>> from tours.models import Reservation
>>> from django.contrib.auth.models import User
>>> user = User.objects.get(username='nika') 
>>> reservations = Reservation.objects.filter(user=user)
>>> for res in reservations:
...     print(res.tour.name, res.reservation_date)
... 
Супер Тур по России 2025-01-22 07:43:10.092116+00:00

Резервирования туров

>>> from tours.models import Tour
>>> tours = Tour.objects.prefetch_related('reservations')
>>> 
>>> for tour in tours:
...     print(f"Тур: {tour.name}")
...     for res in tour.reservations.all():
...         print(f"  - {res.user.username} ({res.reservation_date})")
... 
Тур: Супер Тур по России
  - test (2025-01-21 19:48:21.966985+00:00)
  - nika (2025-01-22 07:43:10.092116+00:00)

Количество бронирований у пользователя

>>> from tours.models import Reservation
>>> user = User.objects.get(username='nika') 
>>> count = Reservation.objects.filter(user=user).count()
>>> print(f"Всего бронирований у {user.username}: {count}")
Всего бронирований у nika: 1

Задание 3.

Вывод даты начала самого старого тура

>>> from django.db.models import Min
>>> from tours.models import Tour
>>> 
>>> oldest_tour = Tour.objects.aggregate(Min('start_date'))
>>> print(oldest_tour['start_date__min'])
2025-01-25
>>>

Укажите самую позднюю дату бронирования

>>> from django.db.models import Max
>>> from tours.models import Reservation
>>> 
>>> latest_reservation_date = Reservation.objects.aggregate(Max('reservation_date'))
>>> print(latest_reservation_date['reservation_date__max'])
2025-03-20 21:57:46.951696+00:00
>>>
